# Asociación Castilla y León para Ucrania (cylucrania.org)

Este repositorio contiene el código fuente de la página web oficial de la **Asociación Castilla y León para Ucrania**, una organización sin ánimo de lucro dedicada a la ayuda humanitaria y el apoyo al pueblo ucraniano desde la comunidad de Castilla y León, España.

La web sirve como plataforma informativa, punto de encuentro para la comunidad ucraniana y canal para gestionar donaciones y ayuda humanitaria.

## 📝 Sobre el Proyecto

Este sitio web fue desarrollado y mantenido de manera altruista durante 4 años (2022-2026) para apoyar la labor de la asociación en respuesta a la crisis humanitaria. Actualmente, el proyecto se libera como código abierto para facilitar su mantenimiento continuo por parte de la asociación y para que otros colectivos puedan beneficiarse de esta herramienta.

### Características principales:

* **Información de Emergencia:** Recursos y contactos para refugiados y colaboradores.
* **Gestión de Donaciones:** Información clara sobre canales de ayuda (IBAN, Bizum, etc.).
* **Logística Humanitaria:** Información sobre la recogida y envío de material sanitario y de primera necesidad.
* **Diseño Responsivo:** Optimizado para dispositivos móviles y escritorio.

## 🚀 Tecnologías Utilizadas

* HTML5 / CSS3 / JavaScript

2. **Abre el proyecto:**
